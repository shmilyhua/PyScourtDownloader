* # S-Court Direct Downloader

A standalone Python script designed to interact directly with the S-Court shop API. It intercepts the localized download URLs generated by the official COM3D2 download client and executes the retrieval directly, bypassing client-side restrictions and proxy requirements.

## Overview

The official S-Court download client occasionally fails to bundle legacy files (such as `cm3d2plg`) alongside modern files (`com3d2plg` and `creplg`) due to hardcoded API command parameters. Previous C#-based local proxies attempted to fix download instability but introduced string parsing bugs that destroyed multi-file queues and enforced incomplete bundles.

This script solves these issues by acting as a direct, closed-loop downloader. It parses the one-time token (`ott`) from the client, manipulates the API's command bitmask to force a complete file bundle, and handles chunked file streaming directly to the local disk.

## Features

* **Direct File Streaming:** Eliminates the need for a local TCP proxy server. It downloads files directly to the execution directory via chunked HTTP streaming to prevent RAM exhaustion.
* **Full Bundle Retrieval:** Overrides the default `cmd=10` parameter used by the official client and C# proxies, injecting `cmd=11` to force the S-Court server to package all available file variants (CM3D2, COM3D2, and CRE).
* **Multi-File Queue Fix:** Corrects a known string parsing bug where the trailing file in a server-generated queue (separated by `!`) is discarded and written as 0 bytes.
* **Continuous Execution:** Runs in a persistent loop, allowing users to queue multiple download links sequentially without restarting the script. Ideal for deployment on headless Linux VPS environments via `tmux` or `screen`.

## Usage

1. Open the official S-Court client and initiate a download for your purchased item.
2. The client will generate a local URL containing your authentication parameters. Copy this URL (it will look similar to `http://localhost:49553/download/itemid/.../ott/...`).
3. Run the Python script:
   ```bash
   python ScourtDirectDownloader.py
   ```
4. Paste the URL into the terminal. The script will parse the tokens, contact the S-Court server, identify the file queue, and execute the download.
5. The `ott` token is strictly single-use. If a download fails, you must generate a new link from the official client.

## Technical Implementation: The `cmd` Bitmask

The S-Court API utilizes the `cmd` parameter as an additive bitmask to determine which files to include in the `Content-Disposition` bundle. 

The base values are defined as:
* `1` = Legacy CM3D2 files (`cm3d2plg_ufp002.zip`)
* `2` = Standard COM3D2 files (`com3d2plg_ufp002.zip`)
* `8` = CR Edit files (`creplg_ufp002.zip`)

By default, the modern client often requests `cmd=10` (2 + 8), which retrieves COM3D2 and CRE files but permanently drops the legacy CM3D2 file. This script automatically enforces `cmd=11` (1 + 2 + 8), compelling the API to return the complete 3-file payload.
